FINANÇAS PESSOAIS — PWA PARA IPHONE (VERSÃO 2)
================================================

O que mudou nesta versão
------------------------
- Design escuro, minimalista e com menos elementos visuais
- Sem gráficos decorativos: foco no saldo, entradas, saídas e orçamento
- Registo detalhado: valor, categoria, data, método de pagamento, descrição e notas
- Edição de movimentos existentes, além de apagar
- Categorias mais diretas e específicas para despesas e receitas
- Histórico filtrável, orçamento mensal e cópias de segurança JSON
- Armazenamento local no navegador; não envia movimentos para servidores
- PWA com ícones e cache para uso offline após a primeira visita

ALOJAR GRATUITAMENTE COM GITHUB PAGES
------------------------------------
1. Descarrega e extrai o ZIP no computador.
2. Inicia sessão em https://github.com/ e cria um repositório chamado, por exemplo, financas-pessoais.
3. Carrega para a raiz do repositório todos os ficheiros e a pasta icons.
4. Abre Settings > Pages. Em Build and deployment, escolhe Deploy from a branch.
5. Seleciona a branch main e a pasta / (root), depois Save.
6. Aguarda a publicação e usa o endereço HTTPS indicado pelo GitHub.

INSTALAR NO IPHONE
------------------
1. Abre o endereço publicado no Safari do iPhone (não em navegação privada).
2. Toca em Partilhar > Adicionar ao ecrã principal. Se aparecer a opção, ativa Abrir como app.
3. Toca em Adicionar e abre a app através do ícone.
4. Regista um movimento de teste e confirma que aparece no histórico.
5. Exporta uma cópia de segurança para testar o fluxo de backup.

CÓPIAS DE SEGURANÇA E PRIVACIDADE
---------------------------------
- Os movimentos e o orçamento ficam no armazenamento local deste navegador/dispositivo.
- Não existe sincronização na nuvem, conta de utilizador nem integração bancária.
- Exporta cópias JSON regularmente e guarda-as num local seguro.
- Importar uma cópia substitui os movimentos atuais; exporta antes os dados existentes.
- Limpar dados do site/Safari, perder ou trocar de iPhone pode apagar os registos.
- O alojamento serve apenas os ficheiros da aplicação; não recebe os movimentos.
- A primeira abertura exige internet e HTTPS; depois, os ficheiros ficam em cache para utilização offline.

Nota: a instalação no ecrã inicial é uma PWA, não uma aplicação nativa distribuída pela App Store.
